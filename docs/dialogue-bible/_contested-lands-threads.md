# THE CONTESTED LANDS — cross-town thread rows (T44 to T54)

To be merged into the README's registry when the dialogue branch lands.
Numbering starts at **T44**: the README table runs T1 to T28 and T40 to
T43, and the town files use T31 to T34 (Northguard) in their own bodies;
T43 is the highest number anywhere on the branch as of 2026-09-04. **The
next free number after this file is T55.**

Both ends of every row are stated. One-directional rows say so and name
the end that needs no change. Actor ids marked "proposed" do not exist yet
and are the ids `contested-lands.md` proposes; correct the table if Band 0
lands them under other names.
