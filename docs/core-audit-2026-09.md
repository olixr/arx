### The five P0s

1. **THE GATE DID NOT OWN ITS KEYS — SHIPPED 0bda0b18, live.** `parseC2S` looked its validator
   up on a plain object; `{"t":"hasOwnProperty"}` from any unauthenticated socket threw inside the
   ws `message` handler, and `t:"constructor"` handed the raw client object back as validated.
   Fixed with an own-key guard pinned over every `Object.prototype` name.
2. **NO CRASH NET — SHIPPED 0bda0b18, live.** No `uncaughtException`/`unhandledRejection`

   dispatch is a try boundary (log once, strike), the tick loop survives a throwing tick, the
   process carries the net (log → normal shutdown with saves → exit 1) and the shutdown drain has
   a 10 s deadline under the supervisor's 15 s SIGKILL.

## §3 Laws this audit adds to the book

1. **THE GATE OWNS ITS KEYS.** A lookup table addressed by client data is `Object.create(null)`,
   a `Map`, or guarded by `Object.hasOwn` — never a bare object literal.
2. **THE FRAME NEVER TAKES THE SERVER DOWN.** Every socket dispatch and every tick body runs
   inside a try boundary that logs and continues; the process carries a crash net that saves
   before it exits, and every drain has a deadline shorter than the supervisor's kill.
3. **A MOVE IS NOT VERBATIM UNTIL A TEST SAYS SO.** No module leaves a monolith without a
   characterization test; movers grep their own artifacts (`\bsrv\b` inside quotes) before the
   commit.
4. **THE BODY IS ONE.** Any async entry (login, resume, plane transfer) does all its awaits
   before it creates state, re-checks its guard once after the last await, and joins an in-flight
   twin instead of racing it.
5. **A STAMP IS A PROMISE THE STAMPER MUST KEEP.** `stageSafe` (or any capability flag) is set
   only on the branch that installed the capable code path — never on the family.
6. **A HAND COPY OF A SHARED SET IS A BUG WAITING FOR THE NEXT MEMBER.** Derive it; pin it by
   value equality, never by grepping source text.
7. **A REGISTRY THAT SHADOWS IS NOT A REGISTRY.** Every id hub throws on a repeat id; every
   `replace*()` runs through one fence that validates before it swaps.
8. **EVERY CACHE NAMES ITS EVICTION AND ITS RESET.** Per-frame/per-tick maps that outlive their
   frame carry an age sweep and are cleared at plane, backend and zoom boundaries; ECS-keyed
   side tables are ECS stores.
9. **THE GATE IS ONE COMMAND.** `npm run gate` is what "green" means; the band pipeline is the
   gate, not a memory of five commands.
